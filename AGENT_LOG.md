## AI Tool Usage

AI tools were used as a development assistant throughout the assignment.

* Used AI to understand the requirements and plan the application structure, including recruiter, preview, and public careers routes.
* Used AI for implementation guidance with Next.js, React, TypeScript, Supabase, authentication, database design, and RLS.
* Used AI to debug issues such as Supabase authentication redirects, environment variables, routing, TypeScript errors, and Render deployment problems.
* Used iterative prompts to refine the job search, filtering, pagination, company branding, sections editor, and publishing functionality.
* When an issue occurred, prompts were refined by providing the exact error, relevant file, current behavior, and expected behavior.
* AI suggestions were reviewed and modified to fit the existing codebase rather than being used blindly.

### Key Learnings

* AI-generated code needs to be tested against the existing project.
* Small changes to components, exports, routes, or database queries can affect other parts of the application.
* Authentication, authorization, and RLS need to be handled carefully in a multi-tenant application.
* Debugging with exact error messages and relevant code produced better results than using broad prompts.
* Iterative development and testing were more effective than trying to generate the complete application in one prompt.
